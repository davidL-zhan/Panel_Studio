# 01 — Design Brief

> DDD 阶段 · 产品设计概要 · AI Panel Studio

---

## 1. 产品目标

AI Panel Studio 是一款本地运行的 AI 圆桌讨论 Web 应用。核心体验是让用户**瞬间召集一支虚拟智库**，围绕任意议题展开深度碰撞——主持人负责调度，专家之间自主举手/抢答/补充/反驳，讨论过程中实时提炼共识与分歧，最终呈现一场沉浸式的 AI 圆桌实况。

**成功标准：**
- 用户在 30 秒内完成"选择话题 → 确认阵容 → 开始观看讨论"
- 实时讨论推进有明确的视觉聚焦（当前发言人）
- Transcript、共识/分歧面板独立滚动，不因内容增长破坏布局
- 断线重连后无缝恢复讨论状态

---

## 2. 目标用户

| 用户群体 | 场景 | 关键需求 |
|----------|------|----------|
| 知识工作者 & 研究人员 | 快速多视角审视议题 | 几分钟内获得不同视角的深度分析 |
| 产品/决策人员 | 方案评审前的预演 | 发现盲点、检验假设 |
| 教育 & 内容创作者 | 将复杂议题结构化呈现 | 沉浸式虚拟专家访谈体验 |

---

## 3. 核心使用场景

1. **创建讨论** — 用户输入话题，选择 4–8 位专家，发起新讨论
2. **确认阵容** — 查看 LLM 生成的嘉宾，选择性替换个别专家，确认后开始
3. **观看讨论** — 实时观看主持人与专家圆桌辩论，聚焦当前发言人
4. **追踪观点** — 同步查看共识/分歧面板和 Transcript，了解观点演化
5. **结束与回顾** — 手动结束讨论，阅读主持人总结，查看完整 Transcript

---

## 4. 设计原则

| # | 原则 | 说明 |
|---|------|------|
| P1 | **聚焦当前发言人** | 讨论进行中，用户的注意力应自然落在"正在说话的人"上——其余区域退为次要 |
| P2 | **信息层级清晰** | 主题 > 发言人 > 发言内容 > 共识/分歧 > Transcript > 操作 |
| P3 | **稳定不跳变** | Transcript 和共识面板独立滚动，内容增长不影响核心舞台布局 |
| P4 | **状态即视觉** | STANDBY / PREPARING / SPEAKING 三种嘉宾状态有明确且克制的视觉差异 |
| P5 | **先状态后内容** | WebSocket 事件推送时，先更新嘉宾状态（谁在准备说话），再展示发言内容 |
| P6 | **断线可恢复** | 网络中断时明确提示，恢复后无缝追赶遗漏事件 |
| P7 | **中文优先** | UI 文案全部中文，字体选择支持 CJK 高质量渲染 |

---

## 5. 视觉关键词

| 关键词 | 视觉表达 |
|--------|----------|
| **演播厅** | 深色背景、舞台聚光灯隐喻、嘉宾区域阵列式布局 |
| **专业** | Inter / 高质量中文字体、克制的间距系统、无装饰性元素 |
| **理性** | 冷色调为主（深蓝灰底 + 暖色仅用于焦点提示）、信息密度适中 |
| **克制** | 动画仅用于状态过渡和焦点转移，不装饰、不炫技 |
| **圆桌对话** | 嘉宾视觉平等的阵列布局，当前发言人通过亮度/边框提升而非大小变化 |
| **实时** | 状态指示器的微妙脉动、WebSocket 连接状态常驻可见 |

---

## 6. 设计边界

### 在范围内
- 桌面端优先（1440px → 1024px → 768px），手机竖屏降级适配
- 中文 UI，深色主题为主（不提供亮色切换）
- 5 个核心页面状态（对应 SDD DiscussionStatus 枚举）
- 4–8 位专家的阵列式布局
- WebSocket 连接的实时状态指示

### 不在范围内（MVP）
- 亮色主题
- 录制/回放功能（仅预留 UI 接口）
- 用户系统/登录
- 国际化（i18n）
- 移动端原生 App

---

## 7. 禁止采用的设计模式

| ❌ 禁止 | 替代方案 |
|---------|----------|
| 左侧固定管理导航栏 | 顶部最小化导航或单页内状态切换 |
| 大量统计卡片 / Dashboard 布局 | 舞台式单焦点布局 |
| 高饱和赛博朋克风格 | 深蓝灰 + 克制的暖色点缀 |
| 过度玻璃拟态（glassmorphism） | 低透明度实色面板 + 微边框 |
| 无意义渐变背景 | 纯色深底 + 聚光隐喻（径向渐变仅用于舞台焦点区） |
| 大量持续动画 | 仅状态过渡动画（150–300ms）+ 发言人聚焦 |
| 只依靠颜色表达状态 | 色彩 + 图标 + 文字标签三重编码 |
| Emoji 作为图标 | Lucide / Heroicons SVG 图标 |
| AI 紫/粉渐变 | 冷色调专业色板 |

## 8. 与 UI UX Pro Max 的关系

设计系统（`design-system/ai-panel-studio/MASTER.md`）由 UI UX Pro Max 生成，提供了颜色、字体、间距、阴影的基线。DDD 阶段在此基础上针对"广播演播厅"场景做了定向调整：

- **保留**：深色背景基调、Inter 字体、间距 Token 体系、阴影层级
- **调整**：主色调从 Indigo 调整为更深沉的中性蓝灰、Accent 绿仅用于状态指示
- **新增**：嘉宾身份色板（10 色，来自 SDD §04-llm-protocol）、语义状态色、共识/分歧色

详见 [`05-design-system.md`](./05-design-system.md)。
