**关键尺寸与行为：**
- 嘉宾区域：固定高度，始终可见，不随内容滚动
- 当前发言区：固定高度（max-height 120px），内容过长时内部滚动
- 底部双栏（共识 + Transcript）：各自独立滚动，高度 = `calc(100vh - 嘉宾区 - 发言区 - TopBar)`
- 双栏默认比例：共识 35% + Transcript 65%（可拖拽调整，MVP 固定比例即可）
- "结束讨论"按钮始终在 TopBar 右侧可见

```
│                                                          │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### WebSocket 重连中

重连时不覆盖页面——仅在 TopBar 显示黄色闪烁圆点 + "重连中..."，并弹出 Toast 通知。用户仍可查看已有的 Transcript 和共识内容。

## 7. 通用布局约束

| 约束 | 说明 |
|------|------|
| TopBar 高度 | 56px 固定 |
| 演播厅嘉宾区 | 固定高度，始终可见 |
| 当前发言区 | max-height 120px，溢出内部滚动 |
| Transcript 面板 | 独立 overflow-y: auto |
| 共识面板 | 独立 overflow-y: auto |
| 页面不出现整页滚动条 | 所有区域内部滚动 |
