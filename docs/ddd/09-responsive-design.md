# 09 — Responsive Design

> DDD 阶段 · 响应式布局方案 · AI Panel Studio

---

## 1. 断点定义

| 断点 | 宽度 | 目标设备 |
|------|------|----------|
| `ultrawide` | ≥ 1440px | 超宽桌面显示器 |
| `desktop` | ≥ 1024px | 标准桌面 / 笔记本 |
| `tablet` | ≥ 768px | 平板横屏 / 小笔记本 |
| `mobile` | < 768px | 手机竖屏 / 平板竖屏 |

## 3. 嘉宾网格布局（按专家数 + 断点）

### 3.1 4 位专家

| 断点 | 布局 |
|------|------|
| ≥ 1024px | 4 列，每列 1 位专家 |
| 768–1023px | 2×2 网格 |
| < 768px | 1×4 垂直列表 |

### 3.2 5 位专家

| 断点 | 布局 |
|------|------|
| ≥ 1024px | 上排 3（居中）+ 下排 2（居中） |
| 768–1023px | 3+2 错行 或 2×3（最后一个占半行居中） |
| < 768px | 1×5 垂直列表 |

### 3.3 6 位专家

| 断点 | 布局 |
|------|------|
| ≥ 1024px | 3×2 网格 |
| 768–1023px | 2×3 网格 |
| < 768px | 1×6 垂直列表 |

### 3.4 7 位专家

| 断点 | 布局 |
|------|------|
| ≥ 1024px | 上排 4 + 下排 3（居中） |
| 768–1023px | 2×4（最后一格空）或 2×3 + 1 居中 |
| < 768px | 1×7 垂直列表 |

### 3.5 8 位专家

| 断点 | 布局 |
|------|------|
| ≥ 1024px | 4×2 网格 |
| 768–1023px | 2×4 网格 |
| < 768px | 1×8 垂直列表 |

## 4. 演播厅布局适配

### 桌面 (≥ 1024px)
```
┌──────────────────────────────────────┐
│          TopBar                       │
├──────────────────────────────────────┤
│        主持人 (居中)                  │
│    专家网格 (固定高度)                │
│    当前发言横幅 (max-h 120px)        │
├────────────────┬─────────────────────┤
│ 共识面板 (35%) │ Transcript (65%)    │
│ 独立滚动        │ 独立滚动            │
└────────────────┴─────────────────────┘
```

### 平板 (768–1023px)
```
┌──────────────────────────────┐
│       TopBar                 │
├──────────────────────────────┤
│   主持人 (居中)               │
│   专家网格 (响应式列数)       │
│   当前发言横幅                │
├──────────────────────────────┤
│ [共识/分歧] [Transcript]  Tab │
│ ┌────────────────────────┐   │
│ │  选中的面板内容         │   │
│ │  独立滚动               │   │
│ └────────────────────────┘   │
└──────────────────────────────┘
```

### 手机 (< 768px)
```
┌──────────────────┐
│  TopBar (精简)    │
├──────────────────┤
│  话题标题         │
│  嘉宾列表 (垂直)   │
│  当前发言         │
├──────────────────┤
│ [共识] [Transcript]│
│  选中的面板       │
│  (全高滚动)       │
└──────────────────┘
```

**手机降级要点：**
- 嘉宾卡片改为紧凑横排（色块 + 姓名 + 状态指示器），不再显示完整职业/立场
- 点击嘉宾卡片可展开详情（小弹窗）
- 共识/Transcript 使用底部 Tab Bar 切换
- "结束讨论"按钮固定在底部（不随内容滚动）

## 5. 首页适配

| 断点 | 布局 |
|------|------|
| ≥ 768px | 内容 max-width 720px 居中；创建区域输入框 + 选择器 + 按钮同行 |
| < 768px | 内容全宽 padding 16px；创建区域垂直堆叠（话题输入 → 人数选择 → 按钮各占一行） |

---

## 6. 通用响应式规则

```css
/* 基础栅格 */
--grid-gap: clamp(12px, 2vw, 24px);

/* 嘉宾卡片最小宽度 */
.panelist-card {
  min-width: clamp(140px, 18vw, 200px);
}

/* 面板高度：视口自适应 */
.transcript-panel,
.consensus-panel {
  max-height: calc(100vh - var(--topbar-height) - var(--stage-height) - var(--speech-height));
}
```
